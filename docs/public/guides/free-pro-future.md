# Differences Between Future Free and Pro

There is a Free version and a Pro version of [PublishPress Future](https://publishpress.com/links/future). This table has an overview of the different features in each version:

|  | Future Free [#](#0-toc-title) | Future Pro [#](#1-toc-title) |
| --- | --- | --- |
| Support for post, pages, and custom post types |  |  |
| Select action dates when editing a post |  |  |
| “Quick Edit” and “Bulk Edit” support |  |  |
| Automatically move posts to “Draft” status |  |  |
| Automatically delete posts or move to trash |  |  |
| Automatically add, remove, or replace taxonomy terms |  |  |
| Email notifications of post chanages |  |  |
| Show expiry dates with a shortcode |  |  |
| Expiration log to record all your post changes |  |  |
| Workflows: Use multiple extra triggers |  |  |
| Workflows: Schedule workflows to start when you choose |  |  |
| Workflows: Use multiple extra steps |  |  |
| Workflows: Send emails when a workflow is complete |  |  |
| Workflows: Use conditional if/else steps in workflow |  |  |
| Actions: Move posts to custom statuses |  |  |
| Actions: Use other plugins to control Future Actions |  |  |
| Actions: Schedule actions based on the post’s publishing date |  |  |
| Remove PublishPress ads and branding |  |  |
| Priority, personal support |  |  |
