# Schedule Changes to WooCommerce Products

The [PublishPress Future](https://publishpress.com/links/future) plugin allows you to schedule automatic changes to posts, pages and other content types including WooCommerce products.

To enable this feature follow these steps:

- Go to Future Actions > Post Types.
- Check the “Active” box in the “Product” area.
- Click “Save Changes”.

![Future Actions WooCommerce](https://docs-media.publishpress.com/publishpress-future/future-actions-products-0812b6660a.webp)

After you enable the [PublishPress Future](https://publishpress.com/links/future) setting for WooCommerce products, you will see the “PublishPress Future” option in the right sidebar when editing a product. You can see the “PublishPress Future” metabox in the screenshot below.

![WooCommerce and PublishPress Future](https://docs-media.publishpress.com/publishpress-future/woocommerce-future-d6a9a93aba.webp)

The “PublishPress Future” setting will also be available for the Quick Edit and Bulk Edit features in WooCommerce. You can see the “Quick Edit” option for PublishPress Future in the screenshot below:

![WooCommerce and PublishPress Future Quick Edit](https://docs-media.publishpress.com/publishpress-future/woocommerce-quick-start-ddff55f262.webp)
