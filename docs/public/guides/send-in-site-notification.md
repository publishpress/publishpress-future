# Send In-Site Notification (Pro)

This feature requires the Pro version of the PublishPress Future plugin.

“Send in-site notification” is one of the steps available in the “Action Workflows” feature of the [PublishPress Future](https://publishpress.com/links/future) Pro plugin. This step will send a customizable message that can be seen inside your WordPress site. In this screenshot below, you can see an alert notification:

![In-site Alert notification ](https://docs-media.publishpress.com/publishpress-future/insite-notifications-alert-b12da0dc08.webp)

When the notification icon is clicked, you will see a notification sidebar appear with your message, as in this screenshot below.

![](https://docs-media.publishpress.com/publishpress-future/insite-notification-sidebar-257df9418a.webp)

You can add an “Send in-site notification” step from the “Actions” tab of the “Action Workflows” area.

![Send in-site notification](https://docs-media.publishpress.com/publishpress-future/insite-notification-d99ff3478f.webp)

The settings for the Send Email step are available in the right sidebar:

- **Recipient**: A comma-separated list of user names, ids, emails or user roles to send the message to.
- **Subject**: This can be customized and will appear in the notification area.
- **Message**: This can be customized and will appear in the notification area.

![Settings for the insite notifications](https://docs-media.publishpress.com/publishpress-future/in-site-notificaton-settings-b717d94213.webp)

There are variables available to customize the notifications sent by Action Workflows. To see the variables, click the brackets icon shown in this screenshot:

![Insite notification settings](https://docs-media.publishpress.com/publishpress-future/insite-variables-5eabf58ad7.webp)

You will now see a selection of variables that can be added to your notification settings, as in this screenshot below:

![Insite notification settings](https://docs-media.publishpress.com/publishpress-future/email-insite-notification-69ccc7627d.webp)
