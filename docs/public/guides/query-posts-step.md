# Query Posts (Pro)

This feature requires the Pro version of the PublishPress Future plugin.

“Query Posts” is one of the steps available in the “Action Workflows” feature of the [PublishPress Future](https://publishpress.com/links/future) Pro plugin. This step retrieves multiple posts to serve as the input for other steps. You can add a “Query Posts” step from the “Advanced” tab of the “Action Workflows” area.

![](https://docs-media.publishpress.com/publishpress-future/query-posts-c73e4b4d91.webp)

The settings for the Query Posts step are available in the right sidebar:

- **Post Type**
- **Post ID**
- **Post Status**

![Query Posts settings](https://docs-media.publishpress.com/publishpress-future/query-post-settings-31398947f4.webp)
