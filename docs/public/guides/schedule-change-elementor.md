# Schedule Changes to Elementor Posts

The [PublishPress Future](https://publishpress.com/links/future) plugin allows you to schedule automatic changes to posts, pages and other content types using Elementor.

To enable this feature follow these steps:

- Go to Future > Post Types.
- Check the “Active” box for the post type you’re using with Elementor.
- Click “Save Changes”.

After you enable the [PublishPress Future](https://publishpress.com/links/future) setting for Elementor content, you will see the “PublishPress Future” option in the right sidebar when editing your posts. You can see the “PublishPress Future” metabox in the screenshot below.
