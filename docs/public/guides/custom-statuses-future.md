# Schedule Posts to Move to Custom Statuses

The Pro version of [PublishPress Future](https://publishpress.com/links/future) allows you to schedule changes to WordPress posts, including moving them to custom statuses. This feature is often used together with the [PublishPress Statuses](https://publishpress.com/links/statuses) plugin.

In the screenshot below, we’re using the [PublishPress Statuses](https://publishpress.com/links/statuses) plugin which has four custom statuses: Approved, Assigned, In Progress, Pitch. Using [PublishPress Future](https://publishpress.com/links/future), you can set up an automatic action that will move this post to a custom status at a date and time of your choice.

![Change WooCommerce posts to a status](https://docs-media.publishpress.com/publishpress-future/future-statuses-f42d86435f.webp)

In this next example, we have enabled PublishPress Future Pro for WooCommerce Orders. WooCommerce has a wide variety of custom statuses for orders: In Progress, Failed, Pending Payment, Processing, On hold, Completed, Cancelled, Refunded, Failed, and Draft. Using PublishPress Future, you can set up an automatic action that will move this WooCommerce order to a custom status at a date and time of your choice.

![WooCommerce products and custom statuses](https://docs-media.publishpress.com/publishpress-future/woocommerce-custom-status-f6a7fd522c.webp)
