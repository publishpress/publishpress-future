# Scheduled Actions and Logs

[PublishPress Future](https://publishpress.com/links/future) has a screen called “Scheduled Actions”. This provides a logging feature that allows you to keep a detailed record of all the changes that happen to your posts.

![Scheduled Actions](https://docs-media.publishpress.com/publishpress-future/scheduled-actions-button-a327799e0f.webp)

In the screenshot below, you see the “Scheduled Actions” area. [PublishPress Future](https://publishpress.com/links/future) records at least key data points for all changes:

- **Action**: Which action is or was scheduled.
- **Status**: Whether the action is complete, pending, or canceled.
- **Arguments**: The post that the action was performed on.
- **Recurrence**: Whether the action is repeating or non-repeating.
- **Scheduled Date**: When the change was or will be made to the post.

![Future Actions table](https://docs-media.publishpress.com/publishpress-future/actions-log-67be1c88b0.webp)

Also, you can click “View log” in the final column, you can dive deeper for more details on any event. Here’s an example in this screenshot below.

![Actions logs details](https://docs-media.publishpress.com/publishpress-future/action-logs-1114962ecb.webp)
