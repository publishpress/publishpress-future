# Post Footer Display for Action Dates

The [PublishPress Future](https://publishpress.com/links/future) plugin allows you to place text inside your articles, showing when an action will happen on your posts.

This image below shows the default text and where it is located. This text can be automatically inserted into your posts, if a Future Action date is set for that post.

![Post Expiry Footer](https://docs-media.publishpress.com/publishpress-future/post-expiry-footer-c069a25767.webp)

*Post Expiry Footer*

This feature can be customized from the [PublishPress Future](https://publishpress.com/links/future) settings area:

- Go to “Future Actions” link in your WordPress admin menu.
- Go to the “Display” tab and look for the “Post Footer Display” options.
