# Manually Run Via Post Row Action (Pro)

This feature requires the Pro version of the PublishPress Future plugin.

“Manually run via post row action” is one of the steps available in the “Action Workflows” feature of the [PublishPress Future](https://publishpress.com/links/future) Pro plugin.

This trigger allows user to manually start the workflow from the main “Posts” screen in WordPress.

![](https://docs-media.publishpress.com/publishpress-future/post-row-action-f160a06243.webp)

When you enable this trigger, this will add an action link to your posts, as shown in the screenshot below. You can click this link to start the workflow.

![Manually run via post row action](https://docs-media.publishpress.com/publishpress-future/run-workflow-link-2fc969f0c0.webp)
