# Manually Run Via Checkbox Step

“Manually run via checkbox” is one of the steps available in the “Action Workflows” feature of the [PublishPress Future](https://publishpress.com/links/future) Pro plugin.

This trigger allows user to manually start the workflow. This workflow trigger can be used via the post editing screen or the Quick Edit panel. You can add a “Manually run via checkbox” step from the “Triggers” tab of the “Action Workflows” area.

![](https://docs-media.publishpress.com/publishpress-future/manually-run-checkbox-e1ea8c0141.webp)

When this trigger is enabled, users will be able to manually enable the workflow inside posts, using this metabox:

![Workflow metabox](https://docs-media.publishpress.com/publishpress-future/workflow-metabox-ba2de41799.webp)

This setting will also be available via the “Quick Edit” area of each post:

![Quick Edit action workflows](https://docs-media.publishpress.com/publishpress-future/enabled-workflows-c4b479c742.webp)
