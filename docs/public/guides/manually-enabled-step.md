# Manually Run Via Future Actions Box

“Manually run via Future Actions Box” is one of the steps available in the “Action Workflows” feature of the [PublishPress Future](https://publishpress.com/links/future) Pro plugin.

This trigger allows user to manually start the workflow. This trigger can be manually activated using the core “Future Actions” box. You can add a “Manually run via Future Actions box” step from the “Triggers” tab of the “Action Workflows” area.

![Manually run via Future Actions box](https://docs-media.publishpress.com/publishpress-future/manually-run-future-actions-8fbc8ded0e.webp)

There are no settings for this step because it relies on the settings from the Future Actions box. When this trigger is enabled, users will be able to manually enable the workflow inside posts, using this metabox. “Trigger workflow” will be available as a choice.

![Metabox workflow](https://docs-media.publishpress.com/publishpress-future/future-trigger-a9f4db26ca.webp)

This setting will also be available via the “Quick Edit” area of each post. “Trigger workflow” will be available as choice.

![Quick Edit workflow](https://docs-media.publishpress.com/publishpress-future/future-action-check-b157f48cb4.webp)
