# Imports and Metadata Scheduling (Pro)

This feature requires the Pro version of the PublishPress Future plugin.

[PublishPress Future](https://publishpress.com/links/future) Pro supports imports from external data sources. You can import posts and automatically create Future Actions associated with those posts.

The best approach way to import posts is to use [the Metadata Scheduling feature](https://publishpress.com/knowledge-base/metadata-scheduling/). [This post](https://publishpress.com/knowledge-base/metadata-scheduling-technical/) explains the technical details of [PublishPress Future](https://publishpress.com/links/future), but it’s not currently possible to import directly to the `ppfuture_actions_args` table.

If you’re using a plugin such as [WP All Import](https://wordpress.org/plugins/wp-all-import/) or [WP Import Expor](https://wordpress.org/plugins/wp-ultimate-csv-importer/)t, you can match up the import tables with the fields you have selected in the Metadata Scheduling feature.
