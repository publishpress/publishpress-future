# Default Actions for Post Types

The Future Actions feature in [PublishPress Future](https://publishpress.com/links/future) has an option to automatically create an action for new posts. For example, you can choose to create a new Future Action that will move all posts to the Draft status after 30 days.

Go to “Future” then “Settings” in your WordPress admin menu and click the “Post Types” tab. Here you can choose defaults for each post type.

- **Active**: This will enable or disable [PublishPress Future](https://publishpress.com/links/future) for the whole post type.
- **Automatically create actions**: Is PublishPress Future enabled by default for new posts.
- **Taxonomy**: Choose the taxonomy to be used for actions.
- **Default Action**: This is the default choice, but users can override this.
- **Default Date/Time Offset**: Set the default expiration date to be used when creating a new post of this type.
- **Who to notify**: Each post type can have notifications sent to these email addresses.

*Post Default*

In the Pro version of PublishPress Future there will be two more settings:

- **Custom statuses**: Allow users to automatically move posts to custom statuses. [Find out more](https://publishpress.com/knowledge-base/custom-statuses-future/).
- **Enable Metadata scheduling**: Use the post metadata to control the scheduling of Future actions in your content. [Find out more](https://publishpress.com/knowledge-base/metadata-scheduling/).
