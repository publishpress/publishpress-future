# Email notification when enabled

## Scenario

With **Enable Email Notification?** set to **Enabled** on **Future → Notifications**, a past-due **Change status to Draft** action runs for a published post. After the queue, the post is Draft and the site administrator receives an email whose subject includes **Future Action Complete** and the post title.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Open **Future → Notifications** and set **Enable Email Notification?** to **Enabled**. Save if changed.
4. Note the site administrator email address (notification recipient).
5. Create or open a **published** post that has **no** Future Action yet. Use a distinctive post title.
6. In the block editor, open the **Future Actions** panel, check **Enable Future Action**, set **Change status to Draft**, and set the date to **yesterday at 09:00** (site timezone).
7. Save/update the post.
8. Clear or capture outbound mail for the test harness (so new messages are observable).
9. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
10. In wp-admin, confirm the post status is **Draft**.
11. Inspect mail delivered to the **site administrator** address.

## Expected result

- Post status is **Draft** in wp-admin.
- An email arrived at the site administrator address whose **subject** contains **Future Action Complete** and the **post title**.

## Edge cases

- None.
