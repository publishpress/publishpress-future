# Corrupted future-action meta recovery

## Scenario

The test harness seeds **corrupted** future-action post meta and a **pending** Action Scheduler row that would **Change status to Draft** on a published post. After the queue runs, the post stays published; the block editor loads and **Enable Future Action** is unchecked.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Create or open a **published** post that has **no** valid Future Action configured in the UI.
4. Use the harness to seed **corrupted** future-action meta on that post and a **pending** scheduled action that would change status to **Draft** (do not configure the action via the Future Actions panel for this case).
5. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
6. In wp-admin, open **Posts → All Posts** and confirm post status.
7. Open the post in the block editor and inspect the **Future Actions** panel (**Enable Future Action** checkbox).

## Expected result

- Post status remains **Published** in wp-admin.
- The block editor loads without error.
- **Enable Future Action** is **unchecked** in the Future Actions panel.

## Edge cases

- None.
