# Change status to Trash

## Scenario

An administrator schedules a past-due Future Action on a published post to **Change status to Trash**. After the Action Scheduler queue runs, the post is in the trash in wp-admin.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Create or open a **published** post that has **no** Future Action configured yet. Note the post title.
4. In the block editor, open the **Future Actions** panel and check **Enable Future Action**.
5. Set the action to **Change status to Trash** and the date to **yesterday at 09:00** (site timezone).
6. Save/update the post.
7. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
8. In wp-admin, check **Posts → All Posts** and **Posts → Trash** for the post.

## Expected result

- The post does not appear among published posts.
- The post appears under **Trash** (or shows trashed status) in wp-admin.

## Edge cases

- None.
