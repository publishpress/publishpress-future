# Delete

## Scenario

An administrator schedules a past-due Future Action on a published post to **Delete**. After the Action Scheduler queue runs, the post is permanently removed from wp-admin lists.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Create or open a **published** post that has **no** Future Action configured yet. Note the post title.
4. In the block editor, open the **Future Actions** panel and check **Enable Future Action**.
5. Set the action to **Delete** and the date to **yesterday at 09:00** (site timezone).
6. Save/update the post.
7. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
8. In wp-admin, search **Posts → All Posts** and **Posts → Trash** for the post by title.

## Expected result

- The post is not listed under **All Posts**.
- The post is not listed under **Trash** (permanently deleted).

## Edge cases

- None.
