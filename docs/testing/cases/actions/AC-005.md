# Stick

## Scenario

An administrator schedules a past-due Future Action on a published, non-sticky post to **Stick**. After the Action Scheduler queue runs, the post is sticky and remains published in wp-admin.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Create or open a **published** post that is **not sticky** and has **no** Future Action configured yet.
4. In the block editor, open the **Future Actions** panel and check **Enable Future Action**.
5. Set the action to **Stick** and the date to **yesterday at 09:00** (site timezone).
6. Save/update the post.
7. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
8. In wp-admin, open **Posts → All Posts** (or edit the post) and check sticky indicator and status.

## Expected result

- The post is marked **sticky** (e.g. “Sticky” in the posts list or sticky control on edit).
- Post status remains **Published**.

## Edge cases

- None.
