# Add extra categories

## Scenario

An administrator schedules a past-due Future Action to **Add extra categories** on a published post in **Alpha** only. The action adds **Beta**. After the queue runs, the post is in both categories (verified in wp-admin).

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Ensure categories **Alpha** and **Beta** exist.
4. Create or open a **published** post assigned **only** to **Alpha**, with **no** Future Action yet.
5. In the block editor, open the **Future Actions** panel and check **Enable Future Action**.
6. Set the action to **Add extra categories**, select **Beta**, and set the date to **yesterday at 09:00** (site timezone).
7. Save/update the post.
8. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
9. Edit the post in wp-admin and inspect **Categories**.

## Expected result

- The post is assigned to **Alpha** and **Beta**.

## Edge cases

- None.
