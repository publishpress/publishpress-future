# Future-dated action not run early

## Scenario

An administrator schedules **Change status to Draft** with a date **7 days in the future** on a published post. Running the Action Scheduler queue before that date must not change the post; the Future Actions panel still shows the scheduled action.

## Steps

1. Sign in as an **administrator**.
2. Confirm **Posts** is active for Future actions (**Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`), post type **post**).
3. Create or open a **published** post that has **no** Future Action configured yet.
4. In the block editor, open the **Future Actions** panel and check **Enable Future Action**.
5. Set the action to **Change status to Draft** and the date to **7 days from now at 09:00** (site timezone)—not yesterday.
6. Save/update the post.
7. Run the site Action Scheduler queue (the harness runs pending actions; do not click around WP-Cron in wp-admin).
8. In wp-admin, confirm the post status on **Posts → All Posts**.
9. Reopen the post in the block editor and inspect the **Future Actions** panel.

## Expected result

- Post status remains **Published**.
- **Enable Future Action** remains checked and the panel still shows the scheduled **Change status to Draft** action with the future date.

## Edge cases

- None.
