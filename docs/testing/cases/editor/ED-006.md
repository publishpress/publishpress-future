# Stick and datetime persist in Classic Editor

## Scenario

The **Classic Editor** plugin is active. Post type **Posts** is active for Future. The same persist flow as ED-005 runs in the Classic Editor metabox: enable action, **Stick**, future date, **09:00**, save, reload, values match.

## Preconditions

- Install and activate the **Classic Editor** plugin so post edit screens use the classic layout.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab).
3. Ensure **Posts** has **Activate the PublishPress Future actions for this post type** checked; save if needed.
4. Open **Posts → Add New** and confirm the **Classic Editor** interface loads (not the block editor).
5. Locate the **Future Actions** metabox (default title) in the editor screen (typically below the content area or in a sidebar metabox region).
6. Check **Enable Future Action** if unchecked.
7. Select **Stick** in the **Action** control.
8. Set the **date** to a date at least 7 days in the future (e.g. the 15th of next month).
9. Set the **time** to **09:00**.
10. Click **Save Draft**.
11. Reload the post edit screen.
12. In the **Future Actions** metabox, assert **Enable Future Action** is **checked**.
13. Assert **Action** shows **Stick**.
14. Assert **date** and **time** match steps 8–9.

## Expected result

- Classic Editor metabox uses default title **Future Actions** and checkbox label **Enable Future Action**.
- **Stick**, date, and **09:00** persist after save and reload, matching block editor behavior in ED-005.

## Edge cases

- Metabox screen options: if **Future Actions** is hidden via **Screen Options**, enable it before assertions.
