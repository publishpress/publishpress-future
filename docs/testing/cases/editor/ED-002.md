# Panel hidden when post type inactive

## Scenario

The **Posts** post type is not active for PublishPress Future. A new post in the block editor must not show the Future Actions panel.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab).
3. Under **Post Types**, locate **Posts**.
4. Uncheck **Activate the PublishPress Future actions for this post type** for **Posts**.
5. Click **Save changes**.
6. Open **Posts → Add New** to load the block editor for a new post.
7. Open the **Document** sidebar and review all plugin-related panels.

## Expected result

- No panel titled **Future Actions** appears in the block editor sidebar.
- No control labeled **Enable Future Action** appears anywhere on the new post screen.
- The editor loads normally (no fatal error, no blank screen).

## Edge cases

- Re-activating the post type after this test restores the panel (covered by ED-001); do not leave **Posts** inactive if subsequent cases in the same run require an active post type unless the harness resets settings between cases.
