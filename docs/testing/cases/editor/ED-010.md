# Future Action column shows Stick date

## Scenario

A post has an enabled future **Stick** action with a known date. The **Posts** list shows that date in the **Future Action** column (singular header).

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Ensure **Posts** is active on **Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`).
3. Create or edit a post; in **Future Actions**, check **Enable Future Action**, select **Stick**, set **date** to a date at least 7 days in the future (e.g. the 15th of next month), set **time** to **09:00**, and **Update** or **Publish**.
4. Note the formatted date string the plugin uses on the edit screen (or the raw date chosen).
5. Open **Posts → All Posts**.
6. If the **Future Action** column is not visible, open **Screen Options** and enable the column whose header is **Future Action** (singular).
7. Locate the row for the post from step 3.
8. Read the cell under the **Future Action** column header for that row.

## Expected result

- The list table includes a column header **Future Action** (not plural).
- The cell for the configured post displays information that includes or corresponds to the **Stick** action’s scheduled **date** (human-readable list formatting is acceptable if it represents the same calendar date saved in step 3).

## Edge cases

- Posts without an action may show an empty cell or em dash; this case only asserts the post with a configured action.
- Column sort/filter behavior is out of scope unless it hides the column entirely.
