# Panel visible when post type active

## Scenario

The **Posts** post type is active for PublishPress Future. An author creates a new post in the block editor and should see the Future Actions panel in the document sidebar.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab).
3. Under **Post Types**, locate **Posts**.
4. Check **Activate the PublishPress Future actions for this post type** for **Posts** if it is not already checked.
5. Click **Save changes** if the form was modified.
6. Open **Posts → Add New** to load the block editor for a new post.
7. In the block editor, open the **Document** sidebar (gear icon) if it is closed.
8. Expand or scroll the sidebar until plugin panels are visible.

## Expected result

- The sidebar contains a panel titled **Future Actions** (default Metabox Title).
- The panel includes a checkbox labeled **Enable Future Action** (default Checkbox Field Label).
- No PHP notices, fatal errors, or blank editor screen appear.

## Edge cases

- If the panel is collapsed, expanding **Future Actions** reveals the checkbox.
- Custom block editor themes or narrow viewports may require horizontal scroll in the sidebar; the panel title must still be findable by accessible name **Future Actions**.
