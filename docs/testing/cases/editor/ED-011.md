# Custom metabox title and checkbox labels

## Scenario

Admin settings override default labels. **Metabox Title** is **Scheduled change** and **Checkbox Field Label** is **Schedule this change** (defaults remain **Future Actions** and **Enable Future Action**). A new post in the block editor shows the custom strings.

## Steps

1. Log in to **wp-admin** as a user who can manage Future settings.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=admin` (Future Actions, Admin tab).
3. Set **Metabox Title** to **Scheduled change**.
4. Set **Checkbox Field Label** to **Schedule this change**.
5. Click **Save Changes**.
6. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab) and ensure **Posts** is active; click **Save changes** if needed.
7. Open **Posts → Add New** in the block editor.
8. In the document sidebar, assert a panel titled **Scheduled change** is present.
9. Assert the panel does **not** use the default title **Future Actions** as the primary panel heading (custom title replaces it).
10. Assert a checkbox (or toggle) labeled **Schedule this change** is present inside that panel.
11. Assert the checkbox label is not the default **Enable Future Action**.

## Expected result

- Block editor panel title reflects **Metabox Title** setting.
- Enable checkbox label reflects **Checkbox Field Label** setting.
- Editor loads without error.

## Edge cases

- Harness should restore default placeholders **Future Actions** and **Enable Future Action** after the run if other cases assume defaults.
- Classic Editor and Quick Edit may also pick up the same labels; this case asserts block editor only.
