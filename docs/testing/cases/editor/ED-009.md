# Bulk add or update action on two posts

## Scenario

Two published posts have no future action. From **Posts → All Posts**, Bulk Edit with **Add or update action for posts**, set **Stick** and one shared future date/time, update. Both posts show that action and date on their individual edit screens.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Ensure **Posts** is active on **Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`).
3. Create and publish **Post A** and **Post B** with no future actions (harness fixtures or manual creation).
4. Open **Posts → All Posts**.
5. Select the checkboxes for **Post A** and **Post B**.
6. In the bulk actions dropdown above the list, choose **Edit** and click **Apply**.
7. In the Bulk Edit panel, locate **Future Action Update**.
8. Select **Add or update action for posts** (not **— No Change —**).
9. Set **Action** to **Stick**.
10. Set **date** to a date at least 7 days in the future (e.g. the 15th of next month).
11. Set **time** to **09:00** if the bulk form includes time.
12. Record the chosen date and time.
13. Click **Update**.
14. Open **Edit** for **Post A**; in **Future Actions**, assert **Enable Future Action** is **checked**, **Action** is **Stick**, and date/time match step 10–11.
15. Repeat step 14 for **Post B**.

## Expected result

- Bulk Edit exposes **Future Action Update** with options including **— No Change —**, **Add or update action for posts**, **Add action if none exists for posts**, **Update the existing actions for posts**, and **Remove action from posts**.
- After **Add or update action for posts**, both posts persist **Stick** and the same date/time on full edit.

## Edge cases

- Other bulk modes (**Add action if none exists**, **Update the existing actions**, **Remove action from posts**) are out of scope for this case but share the same **Future Action Update** control group.
