# Stick action and datetime persist in block editor

## Scenario

On an existing or new post in the block editor, **Enable Future Action** is on. The author sets action **Stick** with a future date and **09:00** time, saves, reloads, and values match.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab).
3. Ensure **Posts** is active (**Activate the PublishPress Future actions for this post type** checked); save if needed.
4. Open **Posts → Add New** (or edit a draft without an existing future action).
5. In **Future Actions**, check **Enable Future Action** if it is unchecked.
6. Select **Stick** in the **Action** field.
7. Set the **date** to a date at least 7 days in the future (e.g. the 15th of next month).
8. Set the **time** to **09:00**.
9. Record the date and time for assertions.
10. Click **Save draft** (or **Update**).
11. Reload the post edit screen.
12. Assert **Enable Future Action** is **checked**.
13. Assert the **Action** field displays **Stick**.
14. Assert the **date** and **time** fields match the values from steps 7–8.

## Expected result

- Saved **Stick** action and date/time are identical after reload.
- No data loss on the future action fields.

## Edge cases

- Publishing vs draft save: behavior should be the same for persisted action metadata regardless of post status, unless the product explicitly clears actions on publish (not expected here).
