# Classic metabox hidden when post type inactive

## Scenario

The **Classic Editor** plugin is active and **Posts** is inactive for Future. The **Future Actions** metabox must not appear on the classic post edit screen.

## Preconditions

- **Classic Editor** plugin is active.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Open **Future** at `wp-admin/admin.php?page=publishpress-future&tab=defaults` (Future Actions, Post Types tab).
3. Uncheck **Activate the PublishPress Future actions for this post type** for **Posts**.
4. Click **Save changes**.
5. Open **Posts → Add New** and confirm the Classic Editor loads.
6. Search the edit screen for a metabox titled **Future Actions** and for the label **Enable Future Action**.

## Expected result

- No **Future Actions** metabox is present.
- No **Enable Future Action** checkbox is visible on the screen.
- The classic edit screen loads without fatal error or blank content.

## Edge cases

- Restore post type activation after the test if the harness does not reset settings automatically.
