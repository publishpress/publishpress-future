# Corrupted meta in Classic Editor unchecked

## Scenario

Same as ED-012 but on the **Classic Editor** screen: harness-seeded corrupted future-action post meta. The classic edit screen loads; **Enable Future Action** in the **Future Actions** metabox is unchecked; no fatal or blank screen.

## Preconditions

- **Classic Editor** plugin is active.

## Steps

1. Log in to **wp-admin** as a user who can edit posts.
2. Ensure **Posts** is active on **Future Actions → Post Types** (`wp-admin/admin.php?page=publishpress-future&tab=defaults`).
3. Using the test harness, seed **corrupted future-action post meta** on a target post (same harness contract as ED-012).
4. Open that post via **Edit** and confirm the **Classic Editor** layout loads.
5. Wait for the full edit screen including metaboxes.
6. Locate the **Future Actions** metabox; enable via **Screen Options** if hidden.
7. Assert **Enable Future Action** is **unchecked**.
8. Assert the page is not blank and does not show a PHP fatal error.

## Expected result

- Classic Editor loads with corrupted meta present.
- **Enable Future Action** is unchecked in the metabox.
- No PHP fatal and no blank edit screen.

## Edge cases

- Use the same corrupted meta fixture as ED-012 for comparable behavior across editors.
- Block editor regression is covered by ED-012; this case is classic-only.
