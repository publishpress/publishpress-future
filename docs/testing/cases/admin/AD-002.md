# Future menu opens Post Types tab

## Scenario

Opening Future from the admin menu lands on the Post Types (defaults) tab with the correct page heading.

## Steps

1. Sign in as an administrator.
2. Click the **Future** menu item in the admin sidebar (or open `wp-admin/admin.php?page=publishpress-future`).
3. Observe the active settings tab and the main page heading.

## Expected result

1. The browser URL includes `page=publishpress-future` and `tab=defaults` (or the Post Types tab is the default with no conflicting tab).
2. The **Post Types** tab is the active tab.
3. The page shows an **H2** heading **Future Actions**.

## Edge cases

- None.
