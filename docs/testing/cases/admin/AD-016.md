# Metabox labels persist on Admin tab

## Scenario

The administrator customizes metabox title and checkbox label on the Admin tab; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=admin`.
3. Set **Metabox Title** (`expirationdate-metabox-title`) to `Scheduled change`.
4. Set **Checkbox Field Label** (`expirationdate-metabox-checkbox-label`) to `Schedule this change`.
5. Click **Save Changes**.
6. Reload the page.

## Expected result

1. After reload, **Metabox Title** still contains `Scheduled change`.
2. **Checkbox Field Label** still contains `Schedule this change`.

## Edge cases

- None.
