# Email notification recipients persist

## Scenario

With email notifications enabled, the administrator sets administrator inclusion and a notify list; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=notifications`.
3. Set **Enable Email Notification?** (`expired-email-notification`) to **Enabled**.
4. Check **Include Blog Administrators?** (`expired-email-notification-admins`).
5. In **Who to Notify** (`expired-email-notification-list`), enter `qa-future@example.com`.
6. Click **Save** (submit name `expirationNotificationSave`).
7. Reload the page.

## Expected result

1. After reload, **Enable Email Notification?** remains **Enabled**.
2. **Include Blog Administrators?** remains checked.
3. **Who to Notify** still contains `qa-future@example.com`.

## Edge cases

- None.
