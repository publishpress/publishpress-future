# List column style and time format persist

## Scenario

The administrator sets **Future Action Column Style** and **Time format in the date picker** on the Admin tab; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=admin`.
3. Set **Future Action Column Style** (`future-action-column-style`) to **Simplified (simple)**.
4. Click **Save Changes**.
5. Reload the page.
6. Set **Time format in the date picker** (`future-action-time-format`) to **24h**.
7. Click **Save Changes**.
8. Reload the page.

## Expected result

1. After step 5, **Future Action Column Style** still shows **Simplified (simple)** selected.
2. After step 8, **Time format in the date picker** still shows **24h** selected.
3. After step 8, **Future Action Column Style** still shows **Simplified (simple)** selected.

## Edge cases

- None.
