# Default date and time formats persist

## Scenario

The administrator sets default date and time display formats; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=display`.
3. Set **Date Format** (`expired-default-date-format`) to `Y-m-d`.
4. Set **Time Format** (`expired-default-time-format`) to `H:i`.
5. Click **Save Changes**.
6. Reload the page.

## Expected result

1. After reload, **Date Format** still shows `Y-m-d`.
2. **Time Format** still shows `H:i`.

## Edge cases

- None.
