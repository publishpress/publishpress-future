# Calendar Visibility default persists

## Scenario

The administrator sets **Calendar Visibility** radios; each choice persists after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=general`.
3. Under **Calendar Visibility** (`expired-hide-calendar-by-default`), select **Always hidden** (value `1`).
4. Click **Save Changes**.
5. Reload the page.
6. Select **Remember last state** (value `0`).
7. Click **Save Changes**.
8. Reload the page.

## Expected result

1. After step 5, **Always hidden** remains selected.
2. After step 8, **Remember last state** remains selected.

## Edge cases

- None.
