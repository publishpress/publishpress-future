# Future admin menu visibility and access

## Scenario

An administrator can see and use the Future admin menu; a subscriber cannot see it and cannot open the Future Actions screen by URL.

## Steps

1. Sign in as an administrator.
2. In the WordPress admin sidebar, confirm a top-level menu item titled **Future** is present.
3. Sign out.
4. Sign in as a subscriber.
5. Confirm the **Future** menu item is not present in the admin sidebar.
6. While signed in as a subscriber, open `wp-admin/admin.php?page=publishpress-future` directly.

## Expected result

1. The administrator sees the **Future** menu in the sidebar.
2. The subscriber does not see the **Future** menu.
3. The subscriber receives an access-denied response (or equivalent “You do not have permission” message) and does not see the Future Actions admin UI.

## Edge cases

- None.
