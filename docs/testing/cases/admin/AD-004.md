# Default Action for post persists after reload

## Scenario

The administrator sets **Default Action** for **post** to destructive and non-destructive values; each selection survives save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=defaults`.
3. For **post**, set **Default Action** (`expirationdate_expiretype-post`) to **Delete**.
4. Click **Save changes**.
5. Reload the page.
6. For **post**, set **Default Action** to **Stick**.
7. Click **Save changes**.
8. Reload the page.

## Expected result

1. After step 5, **Default Action** for **post** still shows **Delete** selected.
2. After step 8, **Default Action** for **post** still shows **Stick** selected.

## Edge cases

- If **Stick** is unavailable, use **Change status to Draft** (or equivalent status-change action) in steps 6–8 and assert that label after reload.
