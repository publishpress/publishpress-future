# Default Date/Time Offset persists

## Scenario

The administrator sets the general **Default Date/Time Offset**; the value persists after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=general`.
3. In **Default Date/Time Offset** (`expired-custom-expiration-date`), enter `+1 month`.
4. Click **Save Changes**.
5. Reload the page.

## Expected result

1. After reload, **Default Date/Time Offset** still contains `+1 month`.

## Edge cases

- None.
