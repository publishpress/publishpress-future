# Automatically create actions for post

## Scenario

The administrator toggles **Automatically create actions** for **post**; the setting persists after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=defaults`.
3. For **post**, turn on **Automatically create actions** (`expirationdate_autoenable-post`).
4. Click **Save changes**.
5. Reload the page.
6. For **post**, turn off **Automatically create actions**.
7. Click **Save changes**.
8. Reload the page.

## Expected result

1. After step 5, **Automatically create actions** for **post** remains on (checked).
2. After step 8, **Automatically create actions** for **post** remains off (unchecked).

## Edge cases

- None.
