# Role permissions for Future actions

## Scenario

The administrator configures which roles may create Future actions; **Editor** can be enabled and persists, while **Administrator** stays checked and disabled.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=general`.
3. Under **Choose Which User Roles Can Create Future Actions** (`allow-user-roles[]`), confirm the **Administrator** checkbox is checked and disabled.
4. Check the **Editor** checkbox if it is not already checked.
5. Click **Save Changes**.
6. Reload the page.

## Expected result

1. After reload, **Editor** remains checked under **Choose Which User Roles Can Create Future Actions**.
2. **Administrator** remains checked and disabled (cannot be unchecked).

## Edge cases

- None.
