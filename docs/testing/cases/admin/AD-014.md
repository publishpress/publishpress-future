# Post footer display settings persist

## Scenario

The administrator enables the post footer and sets footer content and style; all three persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=display`.
3. Turn on **Show in Post Footer?** (`expired-display-footer`).
4. Set **Footer Contents** (`expired-footer-contents`) to `Future action on {date}`.
5. Set **Footer Style** (`expired-footer-style`) to `font-style: italic`.
6. Click **Save Changes**.
7. Reload the page.

## Expected result

1. After reload, **Show in Post Footer?** remains on (checked).
2. **Footer Contents** still contains `Future action on {date}`.
3. **Footer Style** still contains `font-style: italic`.

## Edge cases

- If **Footer Style** is not a text input on this edition, record the control type and assert the chosen style is still applied in the saved setting.
