# Shortcode wrapper settings persist

## Scenario

The administrator sets shortcode wrapper element and class; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=display`.
3. Set **Shortcode Wrapper** (`shortcode-wrapper`) to `div`.
4. Set **Wrapper Class** (`shortcode-wrapper-class`) to `future-action-date`.
5. Click **Save Changes**.
6. Reload the page.

## Expected result

1. After reload, **Shortcode Wrapper** still shows `div`.
2. **Wrapper Class** still shows `future-action-date`.

## Edge cases

- None.
