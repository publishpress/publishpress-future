# Preserve data on deactivation setting persists

## Scenario

The administrator toggles **Preserve Data After Deactivating the Plugin** on Advanced settings; each choice persists after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future-settings&tab=advanced`.
3. Under **Preserve Data After Deactivating the Plugin** (`expired-preserve-data-deactivating`), select **Delete data**.
4. Click **Save Changes**.
5. Reload the page.
6. Select **Preserve data**.
7. Click **Save Changes**.
8. Reload the page.

## Expected result

1. After step 5, **Delete data** remains selected.
2. After step 8, **Preserve data** remains selected.

## Edge cases

- None.
