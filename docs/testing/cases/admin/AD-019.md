# Diagnostics checks show Passed

## Scenario

The administrator opens Diagnostics and verifies core health rows without running repair actions.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future-settings&tab=diagnostics`.
3. Confirm the page heading area shows **Diagnostics and Tools**.
4. Locate the **WP-Cron Status Check** row and read its status.
5. Locate the **Database Schema Check** row and read its status.
6. Do not click any repair or fix buttons on this page.

## Expected result

1. **WP-Cron Status Check** displays **Passed** (or **WP Cron Disabled** on sites with cron disabled).
2. On the default test site, **WP-Cron Status Check** displays **Passed**.
3. **Database Schema Check** displays **Passed**.

## Edge cases

- On environments with WP-Cron disabled, **WP-Cron Status Check** may show **WP Cron Disabled** instead of **Passed**; record the actual value without using repair tools.
