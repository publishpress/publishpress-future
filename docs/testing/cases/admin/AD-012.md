# Past-due actions notification persists

## Scenario

The administrator enables past-due action notifications and sets a notify address; both persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=notifications`.
3. Enable **Enable Past-due Actions Notification?** (`past-due-actions-notification`).
4. In the past-due **Who to Notify** field (`past-due-actions-notification-list`), enter `qa-pastdue@example.com`.
5. Click **Save** (submit name `expirationNotificationSave`).
6. Reload the page.

## Expected result

1. After reload, **Enable Past-due Actions Notification?** remains enabled (on).
2. The past-due **Who to Notify** field still contains `qa-pastdue@example.com`.

## Edge cases

- None.
