# Activate post type for Future actions

## Scenario

The administrator can enable and disable Future actions for the **post** post type; the choice persists after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=defaults`.
3. Locate the **post** row and check **Activate the PublishPress Future actions for this post type** (`expirationdate_activemeta-post`).
4. Click **Save changes**.
5. Reload the page.
6. Uncheck **Activate the PublishPress Future actions for this post type** for **post**.
7. Click **Save changes**.
8. Reload the page.

## Expected result

1. After step 5, **Activate the PublishPress Future actions for this post type** for **post** remains checked.
2. After step 8, that checkbox for **post** remains unchecked.

## Edge cases

- None.
