# Scheduled Actions screen access

## Scenario

An administrator can open the Scheduled Actions screen; a subscriber cannot.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future-scheduled-actions` (submenu under **Action Workflows**, CPT `ppfuture_workflow`).
3. Observe the page heading.
4. Sign out.
5. Sign in as a subscriber.
6. Open `wp-admin/admin.php?page=publishpress-future-scheduled-actions` directly.

## Expected result

1. The administrator sees the **Scheduled Actions** heading (or equivalent page title for that screen).
2. The scheduled actions list or empty state loads without an access error.
3. The subscriber receives an access-denied response (or equivalent) and does not see the Scheduled Actions admin UI.

## Edge cases

- None.
