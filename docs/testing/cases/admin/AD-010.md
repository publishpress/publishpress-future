# Enable Email Notification persists

## Scenario

The administrator toggles **Enable Email Notification?**; Enabled and Disabled each persist after save and reload.

## Steps

1. Sign in as an administrator.
2. Open `wp-admin/admin.php?page=publishpress-future&tab=notifications`.
3. Set **Enable Email Notification?** (`expired-email-notification`) to **Enabled**.
4. Click **Save** (submit name `expirationNotificationSave`).
5. Reload the page.
6. Set **Enable Email Notification?** to **Disabled**.
7. Click **Save** (submit name `expirationNotificationSave`).
8. Reload the page.

## Expected result

1. After step 5, **Enable Email Notification?** still shows **Enabled**.
2. After step 8, **Enable Email Notification?** still shows **Disabled**.

## Edge cases

- None.
