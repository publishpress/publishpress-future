# Auto Layout keeps both nodes and the connection

## Scenario

With a connected trigger and action, **Auto Layout** keeps both nodes and the single edge.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Pick **Post is published**, then add **Move post to status** from the trigger output.
4. Drag the action node to a different place on the canvas.
5. Click **Auto Layout** in the header.
6. Look at the canvas.

## Expected result

1. The canvas has a **Post is published** node and a **Move post to status** node.
2. Exactly one edge connects them.
3. No error notice is shown.

## Edge cases

- Pixel positions are not asserted.
- Clicking **Auto Layout** repeatedly keeps two nodes and one edge.
