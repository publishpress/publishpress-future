# Add an action from the trigger output

## Scenario

Adding **Move post to status** from the trigger's output connects the two nodes.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Pick **Post is published** to replace the placeholder.
4. On the **Post is published** node, activate the output handle (click the add/plus control on the output, or drag from the output handle to empty canvas).
5. In the picker that opens, open the **Actions** tab if needed and choose **Move post to status**.
6. Look at the canvas.

## Expected result

1. The canvas has a **Post is published** node and a **Move post to status** node.
2. Exactly one edge connects the trigger output to the action input.

## Edge cases

- Adding from **Add** → **Actions** without using the output handle may not create an edge; this case requires the output path.
- No extra placeholder node remains after the action is added.
