# Update a published workflow title

## Scenario

On a published workflow, changing the title and clicking **Update** persists the new title in the editor and in the workflows list.

## Steps

1. Sign in as an administrator.
2. Precondition: a published workflow titled `Draft flow QA` exists (trigger **Post is published** → action **Move post to status** with Draft).
3. Open `wp-admin/admin.php?page=future_workflow_editor&workflow={id}` for that workflow.
4. Confirm the header shows **Update**.
5. Change the title to `Draft flow QA updated`.
6. Click **Update**.
7. Wait for the save to finish.
8. Reload the browser on the same editor URL.
9. Read the title field.
10. Open `wp-admin/edit.php?post_type=ppfuture_workflow`.

## Expected result

1. After the reload, the title is `Draft flow QA updated`.
2. The header control still reads **Update**.
3. The list contains `Draft flow QA updated` with status **Published**, and no row titled `Draft flow QA` for this workflow.

## Edge cases

- Clearing the title makes the publish/update control unavailable; not covered here.
- Title with leading/trailing spaces is out of scope.
