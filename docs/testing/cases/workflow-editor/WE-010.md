# Choosing a trigger replaces the placeholder

## Scenario

Picking **Post is published** from the trigger placeholder replaces the placeholder with that trigger node.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`, landing on `admin.php?page=future_workflow_editor`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Confirm the canvas shows the trigger placeholder.
4. Click the placeholder to open the trigger picker (or use **Add** → **Triggers**).
5. Choose **Post is published**.
6. Look at the canvas.

## Expected result

1. The canvas has a node labelled **Post is published**.
2. The trigger placeholder is no longer on the canvas.
3. The canvas has exactly one trigger node.

## Edge cases

- Picking a trigger when one already exists replaces or is blocked; not covered here.
- The inspector may open for the new node; that is acceptable.
