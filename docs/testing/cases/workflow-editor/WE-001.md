# New workflow shows trigger placeholder and welcome guide

## Scenario

An administrator opens a new workflow for the first time. The editor shows a trigger placeholder on the canvas and the welcome guide.

## Steps

1. Sign in as an administrator on a site where the welcome guide has not been dismissed (fresh user state).
2. Open `wp-admin/edit.php?post_type=ppfuture_workflow` and confirm the list is labelled **Action Workflows**.
3. Open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
4. Confirm the browser lands on `wp-admin/admin.php?page=future_workflow_editor`.
5. Wait for the editor canvas to load.
6. Look at the canvas.
7. Look for the welcome guide dialog.

## Expected result

1. The `post-new.php` URL redirects to `admin.php?page=future_workflow_editor`.
2. The canvas contains a trigger placeholder node and no other nodes.
3. A dialog with the label **Welcome to the workflow editor** is visible.
4. The header shows **Add**, **Auto Layout**, **Upgrade to Pro**, **Save draft** and **Publish**.

## Edge cases

- The editor URL opened directly (without `post-new.php`) shows the same placeholder.
- The placeholder is not a trigger node; no trigger label such as **Post is published** is on the canvas yet.
