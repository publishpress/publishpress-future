# Reload keeps title, nodes, connection and Draft setting

## Scenario

After saving, a full browser reload restores the title, the trigger node, the action node, the edge between them, and the Draft status setting.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Set the title to `Draft flow QA`.
4. Pick **Post is published** to replace the trigger placeholder.
5. From the trigger output add **Move post to status**.
6. Select the action node and set its status to **Draft** in the inspector.
7. Click **Save draft** and wait for the save to finish.
8. Reload the browser on the editor URL (`admin.php?page=future_workflow_editor&workflow={id}`).
9. Dismiss the welcome guide if shown.
10. Inspect the title, canvas, and the action node's inspector.

## Expected result

1. Title is `Draft flow QA`.
2. The canvas has a **Post is published** node and a **Move post to status** node.
3. One edge connects the trigger to the action.
4. Selecting the action node shows status **Draft** selected.

## Edge cases

- Unsaved changes made after the last save are not expected to persist.
- Only one edge exists; no duplicate edge appears after reload.
