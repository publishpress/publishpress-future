# Publish a draft workflow changes button to Update

## Scenario

A saved draft with **Post is published** connected to **Move post to status** (Draft) is published. The header control then reads **Update** and the list shows Published.

## Steps

1. Sign in as an administrator.
2. Precondition: a draft workflow titled `Draft flow QA` exists with trigger **Post is published** connected to action **Move post to status** whose status is **Draft**.
3. Open `wp-admin/edit.php?post_type=ppfuture_workflow` and open `Draft flow QA`, landing on `admin.php?page=future_workflow_editor&workflow={id}`.
4. Confirm the header shows **Publish**.
5. Click **Publish**.
6. Wait for the save to finish.
7. Read the label of the same header control.
8. Open `wp-admin/edit.php?post_type=ppfuture_workflow`.
9. Find the row titled `Draft flow QA`.

## Expected result

1. The header control that read **Publish** now reads **Update**.
2. The list row `Draft flow QA` shows status **Published**.

## Edge cases

- The title must be non-empty; **Publish** is unavailable with an empty title.
- Publishing does not remove either node or the edge.
