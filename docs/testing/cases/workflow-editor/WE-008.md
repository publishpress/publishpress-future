# Inserter opens with Triggers and Actions tabs and closes

## Scenario

The header **Add** button opens the inserter with two tabs. The same control, now labelled **Close**, hides it.

## Steps

1. Sign in as an administrator and open `wp-admin/admin.php?page=future_workflow_editor`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Click **Add** in the header.
4. Look at the inserter panel.
5. Click **Close** in the header.

## Expected result

1. After **Add**, the inserter panel is visible.
2. The inserter has tabs **Triggers** and **Actions**.
3. While open, the header control reads **Close**.
4. After **Close**, the inserter panel is hidden and the header control reads **Add**.

## Edge cases

- Clicking **Add** twice in a row alternates open and closed without error.
- The inserter lists no Pro-only step as runnable; see WE-016 for Pro step handling.
