# Pro step is shown with badge and is not placed

## Scenario

In the free plugin the inserter shows the Pro step **On schedule** with a **Pro** badge. Activating it does not add a runnable node. The header offers **Upgrade to Pro**.

## Steps

1. Sign in as an administrator on a site running the free plugin only (Pro not active).
2. Open `wp-admin/admin.php?page=future_workflow_editor`.
3. Dismiss the welcome guide with **Get started** if shown.
4. Note the canvas contents (the trigger placeholder).
5. Click **Add** in the header and open the **Triggers** tab.
6. Find **On schedule** and check its CSS class and badge.
7. Hover the header **Upgrade to Pro** button.
8. Click (activate) **On schedule** in the inserter.
9. Look at the canvas.

## Expected result

1. **On schedule** is listed with CSS class `is-pro-feature` and badge text **Pro**.
2. Near the step, the copy reads: "Currently this step is being skipped. Upgrade to Pro to unlock this feature."
3. After activating it, no runnable **On schedule** node is on the canvas; the canvas content is the same as in step 4.
4. The header shows **Upgrade to Pro** with tooltip "Upgrade to Pro and unlock more features".

## Edge cases

- Activating **On schedule** several times still adds no node.
- Free steps in the inserter (**Post is published**) lack `is-pro-feature` and the **Pro** badge.
