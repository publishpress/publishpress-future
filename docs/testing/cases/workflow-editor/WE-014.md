# Delete the action node removes node and edge

## Scenario

Deleting the **Move post to status** node removes that node and its edge. The trigger remains.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Pick **Post is published**, then add **Move post to status** from the trigger output.
4. Confirm the canvas has two nodes and one edge.
5. Select the **Move post to status** node.
6. Delete it with the node toolbar delete control, or press the Delete key while the node is selected.
7. Look at the canvas.

## Expected result

1. The **Move post to status** node is no longer on the canvas.
2. The edge between the trigger and the action is gone.
3. The **Post is published** node is still on the canvas.

## Edge cases

- Deleting via toolbar and via keyboard give the same result.
- Deleting the action does not delete the workflow itself.
