# Inserter search finds free trigger and action

## Scenario

Searching in the inserter returns the free trigger **Post is published** and the free action **Move post to status**.

## Steps

1. Sign in as an administrator and open `wp-admin/admin.php?page=future_workflow_editor`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Click **Add** in the header.
4. Click the inserter search field and type `Post is published`.
5. Look at the results.
6. Clear the search field and type `Move post to status`.
7. Look at the results.

## Expected result

1. Searching `Post is published` lists **Post is published**.
2. Searching `Move post to status` lists **Move post to status**.

## Edge cases

- Search is case-insensitive: `post is published` finds the same item.
- A term with no match (for example `zzzz-no-match`) shows an empty-result state and neither item.
