# Empty required node field shows validation message

## Scenario

When a required field on **Move post to status** is empty, the sidebar Validation panel shows "The field <label> is required."

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Pick **Post is published**, then add **Move post to status** from the trigger output.
4. Set the workflow title to `Draft flow QA`.
5. Select the **Move post to status** node to open the inspector.
6. Leave the status field empty. If it holds a value, clear it (if the UI allows). If the UI does not allow clearing, clear another required field the inspector marks as required.
7. Open the sidebar and find the Validation panel.
8. Read the message for the emptied field and note its field label.

## Expected result

1. The Validation panel is visible in the sidebar.
2. It shows the message `The field <label> is required.`, where `<label>` is the label of the emptied field.
3. The message stays visible while the field is empty.

## Edge cases

- The header **Publish**/**Update** control is not disabled because of node field errors. With the title set, it can still be clicked; this case only checks the Validation panel.
- Filling the field removes its message from the Validation panel.
