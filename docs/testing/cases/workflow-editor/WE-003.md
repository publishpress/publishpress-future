# Save draft with a title lists workflow as Draft

## Scenario

A new workflow given the title "Draft flow QA" and saved as draft appears in the workflows list with status Draft.

## Steps

1. Sign in as an administrator and dismiss the welcome guide if shown (**Get started**).
2. Open `wp-admin/post-new.php?post_type=ppfuture_workflow` and wait for `admin.php?page=future_workflow_editor`.
3. Set the workflow title to `Draft flow QA`.
4. Click **Save draft** in the header.
5. Wait for the save to finish (the editor stays on the workflow; the URL gains `&workflow={id}` or the editor otherwise reflects a saved draft).
6. Open `wp-admin/edit.php?post_type=ppfuture_workflow`.
7. Find the row titled `Draft flow QA`.

## Expected result

1. Saving completes without an error notice.
2. The list **Action Workflows** contains a row titled `Draft flow QA`.
3. That row shows status **Draft**.

## Edge cases

- With an empty title, **Publish** is unavailable; **Save draft** behavior with an empty title is not asserted here.
- Saving twice does not create a second row with the same title.
