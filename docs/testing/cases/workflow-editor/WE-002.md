# Welcome guide dismiss persists and can be reopened

## Scenario

After dismissing the welcome guide with **Get started**, it stays closed across a full reload. The Options menu can show it again.

## Steps

1. Sign in as an administrator with the welcome guide not yet dismissed.
2. Open `wp-admin/admin.php?page=future_workflow_editor`.
3. In the dialog **Welcome to the workflow editor**, click **Get started** (advance through pages first if the guide has several).
4. Confirm the dialog is closed.
5. Reload the browser on `wp-admin/admin.php?page=future_workflow_editor`.
6. Confirm the dialog is not shown.
7. Open the Options menu (the three-dot control in the header).
8. Click **Welcome guide**.

## Expected result

1. After **Get started**, the **Welcome to the workflow editor** dialog is no longer visible.
2. After the reload, the dialog stays closed.
3. After choosing **Welcome guide** in the Options menu, the **Welcome to the workflow editor** dialog is visible again.

## Edge cases

- Closing the dialog with its close control (instead of **Get started**) is out of scope here.
- Reload is a full browser reload, not an in-app navigation.
