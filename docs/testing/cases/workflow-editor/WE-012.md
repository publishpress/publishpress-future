# Inspector sets status to Draft without saving

## Scenario

Selecting the **Move post to status** node opens the inspector. Choosing Draft keeps Draft selected in the inspector before any save.

## Steps

1. Sign in as an administrator and open `wp-admin/post-new.php?post_type=ppfuture_workflow`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Pick **Post is published**, then add **Move post to status** from the trigger output.
4. Click the **Move post to status** node on the canvas.
5. Confirm the inspector opens for that node.
6. In the status field, choose **Draft**.
7. Do not click **Save draft**, **Publish** or **Update**.
8. Click empty canvas, then click the **Move post to status** node again.

## Expected result

1. The inspector opens when the action node is selected.
2. After step 6, the status field shows **Draft** selected.
3. After reselecting the node (step 8), the status field still shows **Draft**.

## Edge cases

- Leaving the page without saving discards the value; not covered here.
- Other status options exist; only Draft is under test.
