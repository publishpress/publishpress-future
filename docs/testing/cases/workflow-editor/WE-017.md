# Fullscreen mode hides and restores the WP admin menu

## Scenario

The Options menu item **Fullscreen mode** hides the WordPress admin menu and bar. Turning it off shows them again.

## Steps

1. Sign in as an administrator and open `wp-admin/admin.php?page=future_workflow_editor`.
2. Dismiss the welcome guide with **Get started** if shown.
3. Open the Options menu and note whether **Fullscreen mode** is on. If it is on, turn it off first and confirm `#adminmenu` and `#wpadminbar` are visible.
4. Open the Options menu and click **Fullscreen mode** to turn it on.
5. Check `#adminmenu` and `#wpadminbar`.
6. Open the Options menu and click **Fullscreen mode** to turn it off.
7. Check `#adminmenu` and `#wpadminbar` again.

## Expected result

1. With **Fullscreen mode** on, `#adminmenu` and `#wpadminbar` are not visible.
2. With it off, both are visible.

## Edge cases

- Fullscreen mode may already be on by default; step 3 normalizes this.
- The editor canvas stays usable in both states.
