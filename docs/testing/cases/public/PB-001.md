# Post footer shows formatted action date and time

## Scenario

PublishPress Future (free) is active. Display settings are saved with the post footer enabled and fixed date/time formats. A **published** post has an enabled future action scheduled **7 calendar days ahead at 12:00** (site timezone), action **Change status to Draft**. The action queue is **not** run during this case—the post remains published for front-end viewing.

## Steps

1. As an administrator, open **Future Actions → Display** (`wp-admin/admin.php?page=publishpress-future&tab=display`).
2. Set **Date Format** (`expired-default-date-format`) to `Y-m-d`.
3. Set **Time Format** (`expired-default-time-format`) to `H:i`.
4. Enable **Show in Post Footer?** (`expired-display-footer` = Enabled).
5. Set **Footer Contents** (`expired-footer-contents`) to a recognizable string that includes the documented placeholder, for example: `E2E-PB-001 expires ACTIONFULL`.
6. Click **Save Changes**.
7. Create or use the fixture post: status **Published**, future action **enabled**, date **7 days from today**, time **12:00**, action **Change status to Draft**. Do not trigger or wait on the action queue.
8. Log out (or use a private/incognito window with no admin session).
9. View the fixture post on the front end.

## Expected result

- The post footer area shows the **Footer Contents** text with `ACTIONFULL` replaced by the scheduled action datetime.
- The date portion appears as `Y-m-d` (matching the fixture’s action date, seven days ahead).
- The time portion appears as `12:00` in `H:i` form.
- The literal prefix `E2E-PB-001 expires` remains visible so the tester can confirm the configured footer template rendered.

## Edge cases

- If **Show in Post Footer?** is left disabled, this case does not apply—use PB-002 instead.
- If the fixture post has no enabled future action, the footer block should not appear (or should not show a substituted date—match product behavior for posts without a scheduled action).
- Timezone: use the site timezone when interpreting “7 days ahead at 12:00” and when asserting `H:i` output.
